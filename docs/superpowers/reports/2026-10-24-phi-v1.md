## Workflow-child stop requirement

The user's acceptance requirement is to stop each Workflow child independently from the TUI. The native selected-child stop uses the pair `(workflow task ID, agentId)`. The public `Query.stopTask()` route uses a registered SDK task ID. The inspected SDK host has no route from Phi to the native child callback. The native Bash stop is not a Workflow-child pass. See the version-scoped source trace and official SDK contract in the [native report](2026-10-24-phi-native.md).

## Delivered implementation

Phi 0.1.0 is a local terminal UI over the Claude Agent SDK and pi-tui. The SDK owns tools, Workflows, tasks, hooks, MCP, and session persistence. Phi provides streaming views, permissions and questions, task and history inspection, session controls, worktree inspection, explicit local shell commands, attachments, and private shell-output artifacts. The mandatory independent Workflow-child stop is not included.

The pinned runtime dependencies are Claude Agent SDK `0.3.310` and pi-tui `1.4.0`. The declared minimum Node.js version is `22.19`.

## Remaining acceptance

The [implementation plan](../plans/2026-10-24-phi-v1.md) keeps the full acceptance checklist. Open work includes:

- Pass PTY checks on the root integration candidate after the cleanup failure is fixed.
- Run the load test on the root integration candidate.
- Implement and prove independent TUI stop for each Workflow child, including native skipped-child semantics, a continuing sibling, Workflow continuation, and continued main input.
- Complete Ghostty acceptance for paste, multiline input, selection and copy, resize, task navigation, interruption, resume, scrolling, and terminal restoration.
- Complete install, package, and Git workflow checks at the required source.

V1 is complete only when the deterministic, native SDK, and Ghostty gates pass at their required sources. Native acceptance must include independent Workflow-child stop from the TUI, continued input, session resume, checkpoint limits, and truthful Git receipts. Deferred or unverified evidence is not a pass. Rex-specific acceptance and model-quality comparison remain later work.
