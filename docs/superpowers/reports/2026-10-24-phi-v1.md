## Run the checkout

Build Phi with `npm run build`. Start the compiled CLI from a project directory:

```sh
node /path/to/phi/dist/src/cli.js --cwd /path/to/project
```

Phi uses a valid inherited `ANTHROPIC_API_KEY`, then a saved Phi key, then a hidden prompt. See the [launch guide](../../../README.md) for `phi auth login`, `status`, and `logout`. Keep key values out of this repository and chat. Help and version work without credentials.

## Delivered behavior

| Area | Implementation |
| --- | --- |
| Native agent | Claude Agent SDK owns reasoning, tools, subagents, Workflows, settings, hooks, plugins, MCP, and session persistence. |
| Terminal | pi-tui provides streaming Markdown, tool receipts, multiline input, attachments, permission/question dialogs, inspectors, and a command palette. |
| Development | Native Git and `gh` tools remain available. Phi observes worktree/cwd changes and runs explicit local shell commands with private output artifacts. |
| Controls | Model, effort, permissions, foreground interruption, backgrounding, selected-task stop, resume/fork/new, and checkpoint rewind use native SDK controls. |
| Recovery | Process generations reject stale callbacks. Session switches settle old requests, retain rejected drafts, and close old work before opening the target. |

Ctrl+O opens transcript History. Ctrl+Shift+P opens the palette. `/phi questions` reopens hidden requests. Ctrl+C cancels a visible request without closing Phi. Exiting with drafts or remaining work requires confirmation.

The pinned runtime dependencies are `@anthropic-ai/claude-agent-sdk` 0.3.310 and `@earendil-works/pi-tui` 1.4.0. Development uses TypeScript 7.0.2 and `@types/node` 22.20.5. Checks ran on Node 26.12.1. The declared minimum is Node 22.19.

## Read-only GitHub shell check

An isolated driver exercised the compiled runtime from `a2ec6b4` with `FakeQueryHarness.createQuery` injected before app startup. It used a synthetic Phi home, a disposable Git repository, and the real local shell runner. The driver environment omitted provider credentials. The installed `/opt/homebrew/bin/gh` reported version `2.103.2` and used existing GitHub authentication.

The driver submitted these commands through Phi's `!` mode:

```sh
PATH=/opt/homebrew/bin:$PATH GH_PROMPT_DISABLED=1 /opt/homebrew/bin/gh api repos/rexbrahh/phi --jq '{full_name,default_branch}'
PATH=/opt/homebrew/bin:$PATH GH_PROMPT_DISABLED=1 /opt/homebrew/bin/gh pr list --repo rexbrahh/phi --limit 3 --json number,state
```

Both jobs exited with code `0`. The fake SDK received both receipts with `shouldQuery=false`, and the fake terminal buffer displayed both outputs. Repository metadata identified `rexbrahh/phi` and `main`. The PR list returned an empty array. No Anthropic query ran.

This evidence covers read-only CLI commands through the product's shell and receipt paths. Model-driven Git/PR proficiency and human Ghostty acceptance remain unverified.
