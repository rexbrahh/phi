## Workflow-child stop requirement

The acceptance requirement is to stop each Workflow child independently from the TUI. The native selected-child skip uses `(workflowTaskId, agentId)`. The public `Query.stopTask()` route uses a registered SDK task ID and follows that task's lifecycle. These controls have different identities and behavior. SDK `0.3.310` exposes no host route from Phi to the native callback. The native Bash stop does not meet the Workflow-child requirement. See the version-scoped source trace and SDK contract in the [native report](2026-10-24-phi-native.md).

The user authorized an upstream request. [SDK issue 518](https://github.com/anthropics/claude-agent-sdk-typescript/issues/518) requests the existing native operation, stable child identity, and child-specific lifecycle evidence. The request is open. Posting it does not complete this gate.

## Delivered implementation

Phi 0.1.0 is a local terminal UI over the Claude Agent SDK and pi-tui. The SDK owns tools, Workflows, tasks, hooks, MCP, and session persistence. Phi provides streaming views, permissions and questions, task and history inspection, session controls, worktree inspection, explicit local shell commands, attachments, and private shell-output artifacts. The mandatory independent Workflow-child stop is not included.

The pinned runtime dependencies are Claude Agent SDK `0.3.310` and pi-tui `1.4.0`. The declared minimum Node.js version is `22.19`.

## Remaining acceptance

The [implementation plan](../plans/2026-10-24-phi-v1.md) keeps the full acceptance checklist. Open work includes:

- Implement and prove independent TUI stop for each Workflow child, including native skipped-child semantics, a continuing sibling, Workflow continuation, and continued main input.
- Complete Ghostty acceptance for image paste, scrolling, split resizing, multiline input, selection and copy, task navigation, interruption, resume, and terminal restoration.

V1 is complete only when the install, deterministic, native SDK, and Ghostty gates pass at their required sources. Native acceptance must include independent Workflow-child stop from the TUI, continued input, session resume, checkpoint limits, and truthful Git receipts. Deferred or unverified evidence is not a pass. Rex-specific acceptance and model-quality comparison remain later work.
