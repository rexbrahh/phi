## Delivered implementation

Phi 0.1.0 is a local terminal UI over the Claude Agent SDK and pi-tui. The SDK owns tools, Workflows, tasks, hooks, MCP, and session persistence. Phi provides streaming views, permissions and questions, task and history inspection, session controls, worktree inspection, explicit local shell commands, attachments, and private shell-output artifacts.

The pinned runtime dependencies are Claude Agent SDK `0.3.310` and pi-tui `1.4.0`. The declared minimum Node.js version is `22.19`.
