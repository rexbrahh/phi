# Phi 1.0.2

This patch fixes crowded transcripts and session controls.

```sh
brew update
brew upgrade rexbrahh/tap/phi
```

- Routine SDK events stay out of the conversation. Repeated diagnostics share one group. Short previews show the two most recent groups; `/phi diagnostics` shows complete retained details.
- `/model` and `/effort` open keyboard menus with the current SDK choices. Menus preserve drafts, show the selected value, and reject stale validation results after closing or changing sessions.
- Long permission and question dialogs scroll with PgUp/PgDn. Their response controls stay visible. Escape from history restores a request opened before history.
- Command search matches names and descriptions and keeps its filter after resize. The footer shows how to reopen hidden requests or dismiss notices.
- SDK request failures show their cause. Diagnostic text redacts the configured API key. Menus and dialogs have a distinct background.

Closing a menu does not cancel a model or effort change already sent to the SDK. Phi reports the accepted result for the current session.

The picker race has regression tests and extracted Lean and TLA+ models. The models do not verify TypeScript equivalence or native SDK behavior.

The existing Workflow limitation remains: Claude Agent SDK 0.3.310 does not expose the native operation needed to stop each Workflow child independently. This patch does not claim full Claude Code parity.
