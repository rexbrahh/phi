# Phi 1.0.4

Phi now keeps conversation text above routine tool and SDK activity. It also adds searchable sessions, local command completion, and an external prompt editor.

Prompts and replies use inline markers. Native command envelopes display as commands and results. Routine SDK events stay in diagnostics. Idle status excludes stale request phases.

Run `brew update` and `brew upgrade rexbrahh/tap/phi` to update.

- `/phi sessions` searches project sessions by title, branch, or ID. Enter resumes the selection. Escape keeps the current session and draft, and cancels a pending switch confirmation.
- `/phi` subcommands complete in the composer, including pasted commands followed by Tab. Native SDK commands and file references remain available.
- Tool rows show the name, state, and a short description. Successful output uses one preview row. Failures keep three rows. `/phi details` expands retained input and output. `/phi copy` or Ctrl+Shift+Y copies the latest completed answer, or the selected inspector output.
- Ctrl+W, Ctrl+F, Ctrl+Y, and Alt+Backspace retain normal text-editing behavior. Workspace, history search, and copy use Ctrl+Shift+W, Ctrl+Shift+F, and Ctrl+Shift+Y.
- Ctrl+G or `/phi editor` opens VISUAL, EDITOR, or vi. Save and exit to return the draft without sending it. Workspace refresh moves to Ctrl+Shift+G.

The external editor uses a private temporary file. Editor failures retain a recovery file and leave the original draft unchanged. Shutdown uses a bounded wait and reports an error if editor exit cannot be confirmed. Inherited Git directory, worktree, and index overrides are cleared; SSH and signing settings remain available.

Validation passed: 415 automated tests, 16 PTY scenarios, and the package check. The 30,003-event load test measured keyboard-to-frame p95 at 42.8 ms, below the 50 ms limit. Checks include screenshot-derived transcript fixtures, native command parsing, and stream status. Lean and TLC checked the extracted session-cancellation model; they do not prove TypeScript equivalence.

An isolated Ghostty run passed the transcript, model and effort pickers, permission dialog, history, completion, details toggle, and session-picker checks. Copy used a test clipboard. The run used a fake SDK and restored terminal settings and existing windows. Ghostty resize automation was unavailable; PTY resize tests passed.
