# Phi 1.0.4

Phi now provides searchable sessions, local command completion, compact tool inputs, and an external prompt editor. These changes follow established Pi, OpenCode, and Gemini CLI interactions.

Run `brew update` and `brew upgrade rexbrahh/tap/phi` to update.

- `/phi sessions` searches project sessions by title, branch, or ID. Enter resumes the selection. Escape keeps the current session and draft, and cancels a pending switch confirmation.
- `/phi` subcommands complete in the composer. Native SDK commands and file references remain available.
- Tool inputs use one-line summaries. `/phi details` expands or collapses retained input and output previews. `/phi copy` or Ctrl+Shift+Y copies the latest completed assistant answer, or the selected inspector output.
- Ctrl+W, Ctrl+F, Ctrl+Y, and Alt+Backspace retain normal text-editing behavior. Workspace, history search, and copy use Ctrl+Shift+W, Ctrl+Shift+F, and Ctrl+Shift+Y.
- Ctrl+G or `/phi editor` opens VISUAL, EDITOR, or vi. Save and exit to return the draft without sending it. Workspace refresh moves to Ctrl+Shift+G.

The external editor uses a private temporary file. Editor failures retain a recovery file and leave the original draft unchanged. Inherited Git directory, worktree, and index overrides are cleared; SSH and signing settings remain available.

Validation passed: 400 automated tests, 16 PTY scenarios, and the package check. The 30,003-event load test measured keyboard-to-frame p95 at 30.4 ms, below the 50 ms limit. Lean and TLC checked the extracted session-cancellation model; they do not prove TypeScript equivalence.

The research and acceptance scope are recorded in the [usability review](../superpowers/reports/2026-10-26-harness-polish.md). The current Mac lock screen prevented a new Ghostty visual pass.
