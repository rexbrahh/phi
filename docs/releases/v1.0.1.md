# Phi 1.0.1

Phi is a local coding terminal built with the Claude Agent SDK and pi-tui.

## Install

```sh
brew install rexbrahh/tap/phi
```

Start Phi in the project directory where it should work. Run `phi auth login` to save an API key, or enter a key when Phi asks on the first interactive coding launch.

## Included

- Native SDK tools, skills, hooks, plugins, MCP servers, Workflows, and subagents.
- Streaming output, permission and question prompts, task and history views, session controls, workspace inspection, explicit shell commands, and image attachments.
- A private `~/.phi` home for saved authentication and state, plus one-time import of selected Claude Code customizations.

Phi does not provide full Claude Code parity.

## Release note

Release CI now runs mocked clipboard tests with an explicit macOS platform, so Linux CI exercises their intended behavior while retaining a check that non-macOS clipboard calls are rejected.

## Known limitation

Phi 1.0.1 cannot stop each native Workflow child independently from the TUI. With Claude Agent SDK `0.3.310`, `Query.stopTask()` accepts a registered task ID. It does not expose the native selected-child operation `(workflowTaskId, agentId)`. This release does not claim that independent child stop works.
