# Phi 1.0.5

Phi keeps conversation text above routine tool and SDK activity. This release includes the interface changes prepared for 1.0.4.

The 1.0.4 release check found that long localized timestamps could clip branch names in the session picker. No 1.0.4 archive was published. Version 1.0.5 displays branch names before timestamps and adds a regression test.

Run `brew update` and `brew upgrade rexbrahh/tap/phi` to update.

- Prompts and replies use inline markers. Native command envelopes display as commands and results. Routine SDK events stay in diagnostics. Idle status excludes stale request phases.
- `/phi sessions` searches project sessions by title, branch, or ID. Enter resumes the selection. Escape preserves the current session and draft.
- `/phi` subcommands complete in the composer, including pasted commands followed by Tab. Native SDK commands and file references remain available.
- Successful tool output uses one preview row. Failures keep three rows. `/phi details` expands retained data. `/phi copy` copies the latest completed answer or selected inspector output.
- Ctrl+W, Ctrl+F, Ctrl+Y, and Alt+Backspace retain normal editing behavior. Workspace, history search, and copy use Ctrl+Shift+W, Ctrl+Shift+F, and Ctrl+Shift+Y.

Ctrl+G or `/phi editor` opens VISUAL, EDITOR, or vi. Save and exit to return the draft without sending it. Workspace refresh uses Ctrl+Shift+G. Editor failures retain a recovery file and preserve the original draft. Shutdown reports an error if editor exit cannot be confirmed within the bounded wait.

All 416 automated tests passed locally with UTC timestamps. Package validation passed. Earlier checks of the shared changes passed 16 PTY scenarios. The 30,003-event load test measured keyboard-to-frame p95 at 42.8 ms. Lean and TLC checked the extracted session-cancellation model. They do not prove TypeScript equivalence.

An isolated Ghostty run checked the transcript, model and effort pickers, permissions, history, completion, details, and session picker. It used a fake SDK and test clipboard. Ghostty resize automation was unavailable. PTY resize tests passed. See the [usability review](../superpowers/reports/2026-10-26-harness-polish.md).

Claude Agent SDK 0.3.310 still lacks the native operation needed to stop each Workflow child independently. This release does not claim full Claude Code parity.
